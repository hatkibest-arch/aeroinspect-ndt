# AeroInspect NDT — UAV Concrete Surface Inspection

Desktop application for automated post-flight screening of concrete structures (bridges, dams, tunnels) from UAV photogrammetry imagery.

## Key Features
* High-throughput batch triage of concrete surfaces at 180-250+ FPS on Apple Silicon.
* Dynamic defect threshold filtering aligned with ASTM D610 and ACI 224R guidelines.
* Live telemetry dashboard tracking scanned samples, defect count, and defect rate.

## Tech Stack
* Python 3.10+
* Ultralytics YOLOv8
* OpenCV & NumPy
* PyQt6
